# Unit 2 Performance Task (page 98)

Spec for the builder. One guided, multi-part problem with a data table. Original context and numbers; the structure mirrors the book.

## 1. Source page

Page 98: a new pastry shop has been open two weeks. Table "Pastry Shop Customers": Week 1, Week 2 given; Week 3 "?". **Part A** total customers in Weeks 1 and 2. **Part B** difference between Weeks 1 and 2. **Part C** goal of 800 customers in the first 3 weeks — how many must come in Week 3? **Part D** if the shop has 847 visitors in the first 3 weeks, which week has more customers, Week 1 or Week 3, and how many more? **Reflect**: how can you use strategies to add and subtract multi-digit numbers?
(Book answers for reference: A 613, B 35, C 187, D Week 3 = 234, Week 1 has 90 more.)

## 2. Goals and prerequisites

Goal: *I can use a table and add and subtract 3-digit numbers to solve a problem with several parts.*
Skills: read a table; add with regrouping (2-6, 2-10, 2-14); subtract with regrouping (2-7, 2-9, 2-11); missing part toward a goal (2-9); two-step reasoning (2-12); compare (2-13).

## 3. Vocabulary

- **Table** — rows and columns that organize numbers.
- **Total** — all of them together (add).
- **Difference** — how many more or fewer (subtract).
- **Goal** — the number you want to reach.

## 4. Methods used

No new method. Each part names the operation; the child picks any strategy from the unit (partial sums, adjusting, adding up, the algorithm). The app checks the operation choice and the number.

## 5. Activity screens

The task appears in the lesson menu as **Performance Task** with three activities:

1. **Do It Together** (guided; hints, Check, Show Answer, Parent Help) — Version 1 (Juice Stand).
2. **Do It Myself** (no hints until the end; checked at the end with explanations) — Version 2 (Lemonade Stand). Recorded in My Results as "Performance Task" with a per-part score.
3. **Talk About It** — the Reflect prompt (parent-marked, never graded).

Every screen shows the table at the top (sticky on wide screens; repeated above each part on phones). One part per screen, "Part X of 4", Back / Next. Each part is a `parts` question: `choice` "What do you need to do?" + `num` answer(s).

### Version 1 — Juice Stand (Do It Together)

Intro: "Leo helps at a new juice stand. It has been open for two weeks."

Table "Juice Stand Customers": Week 1 · 436 · Week 2 · 378 · Week 3 · ?

| Part | Prompt | Parts | Answer | Hint | Explanation |
|---|---|---|---|---|---|
| A | "How many customers came in Weeks 1 and 2 in all?" | choice: Add / Subtract / Compare only · num | Add · **814** | "In all" means put together. | 436 + 378: 6 + 8 = 14 → 4, regroup; 1 + 3 + 7 = 11 → 1, regroup; 1 + 4 + 3 = 8 → 814. |
| B | "How many more customers came in Week 1 than in Week 2?" | choice: Subtract / Add · num | Subtract · **58** | "How many more" means find the difference. | 436 − 378: add up from 378: + 2 = 380, + 20 = 400, + 36 = 436; 2 + 20 + 36 = 58. |
| C | "The stand's goal is 1,000 customers in the first 3 weeks. How many must come in Week 3 to reach the goal?" | choice: "1,000 − 814" ✓ / "1,000 + 814" / "814 − 436" · num | **186** | Use your answer from Part A. What is still missing to make 1,000? | 814 + 186 = 1,000 (814 + 6 = 820, + 80 = 900, + 100 = 1,000 → 186). |
| D | "Suppose the stand has 1,050 customers in the first 3 weeks. Which week had more customers, Week 1 or Week 3? How many more?" | num "Week 3 customers" · choice Week 1 / Week 3 · num "How many more?" | **236** · **Week 1** · **200** | First find Week 3: take Weeks 1 and 2 away from 1,050. Then compare. | Week 3 = 1,050 − 814 = 236. 436 > 236, so Week 1 had more. 436 − 236 = 200. |

Parent Help per part: A — "Ask which strategy they will use. Any correct strategy is fine." B — "Ask: is adding up or taking away easier here?" C — "Point to Part A's answer. Do we need to add Weeks 1 and 2 again?" D — "This part has two steps. Ask: what do we need to find first?"

### Version 2 — Lemonade Stand (Do It Myself)

Intro: "Ruby runs a lemonade stand that has been open for two weeks."

Table "Lemonade Stand Customers": Week 1 · 463 · Week 2 · 395 · Week 3 · ?

| Part | Prompt | Answer |
|---|---|---|
| A | Customers in Weeks 1 and 2 in all? | Add · **858** |
| B | How many more in Week 1 than Week 2? | Subtract · **68** |
| C | Goal: 1,000 in the first 3 weeks. How many in Week 3? | 1,000 − 858 · **142** |
| D | Suppose 1,075 customers in the first 3 weeks. Week 3? Which week had more, Week 1 or Week 3? How many more? | **217** · **Week 1** · **246** |

### Talk About It (Reflect)

"How can you use strategies to add and subtract big numbers?" `explain` item, parent-marked. Parent prompt: "Ask your child to tell which strategy they used for each part and why. Good answers name a strategy (partial sums, adjusting, adding up, the algorithm) and say something about the numbers ('378 is close to 380, so I added up')."

## 6–8. Practice / On My Own / Test

- Practice Together = Version 1 (4 parts).
- On My Own / assessment = Version 2 (4 parts, 7 graded answers: A choice+num, B choice+num, C choice+num, D three answers). Score = parts fully correct out of 4, shown with the per-part review.
- There is no separate test; Version 2 *is* the independent check. A third version can be generated later with the same structure (two 3-digit weeks with regrouping, goal a round number above their sum).

## 10. Common mistakes and coaching

- Adding all the table numbers for Part B. Fix: "how many more" → difference.
- Forgetting to use Part A in Part C (re-adding or using one week only).
- Part D: comparing Week 1 with 1,050 instead of with Week 3. Fix: find Week 3 first.
- Regrouping slips in 436 − 378 (getting 142 by subtracting smaller-from-larger digits in each place). Fix: add up from 378, or check 378 + 58 = 436.

## 11. Parent Guide content

- **Goal**: use a table and Unit 2 strategies to solve a 4-part problem.
- **Demonstrate**: before starting, read the table together: "What does 436 tell us? What is the '?'"
- **Ask**: "What is this part asking — all together, how many more, or how many are missing?" "Can we use an earlier answer?" "How can you check?"
- **Checklist**: reads the table · adds with regrouping · subtracts with regrouping · finds the missing amount to a goal · solves a two-step comparison · explains a strategy aloud.

## 12. Answer key check

- V1: 436 + 378 = 814 (6+8=14, 1+3+7=11, 1+4+3=8) ✓. 436 − 378 = 58 (378 + 58 = 436) ✓. 1,000 − 814 = 186 (814 + 186 = 1,000) ✓. 1,050 − 814 = 236 (814 + 236 = 1,050) ✓; 436 − 236 = 200 ✓; 436 > 236 ✓.
- V2: 463 + 395 = 858 (3+5=8, 6+9=15, 1+4+3=8) ✓. 463 − 395 = 68 (395 + 68 = 463) ✓. 1,000 − 858 = 142 (858 + 142 = 1,000) ✓. 1,075 − 858 = 217 (858 + 217 = 1,075) ✓; 463 − 217 = 246 (217 + 246 = 463) ✓; 463 > 217 ✓.
- Check by script as well.
