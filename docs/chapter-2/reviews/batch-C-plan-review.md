# Batch C plan review: math and teaching (2-9, 2-10, 2-11, 2-12)

Independent review of `lessons/2-9.md`, `2-10.md`, `2-11.md` and `2-12.md`. I checked each spec against the scanned pages 67–82, `PLAN.md` (Decisions) and `_TEMPLATE.md`.
